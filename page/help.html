Pasos básicos y qué tener a mano (ES/EN)

Español

1. Ten a mano Animation.json, spritemap1.json y spritemap1.png.
2. Abre los archivos con los botones de la izquierda. También puedes arrastrarlos a la app.
3. Si usas anims.xml o anims.json, cárgalo para nombres e índices.
4. Elige la carpeta de salida (Salida).
5. Marca Exportar frames PNG si quieres PNG por frame.
6. Marca Exportar .ase si quieres el archivo final.
7. Si exportas .ase, selecciona la ruta de Aseprite CLI.
8. Presiona Exportar y revisa el Log si hay errores.

English

1. Have Animation.json, spritemap1.json, and spritemap1.png ready.
2. Open the files using the buttons on the left. You can also drag and drop them into the app.
3. If you use anims.xml or anims.json, load it for names and indices.
4. Choose the output folder (Salida).
5. Enable Export frames PNG if you want PNGs per frame.
6. Enable Export .ase if you want the final file.
7. If exporting .ase, select the Aseprite CLI path.
8. Press Export and check the Log for errors.
